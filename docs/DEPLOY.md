## 1. 对照首页：小程序发布流程

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com/) 后，首页会显示 **「小程序发布流程」**，大致如下：

```
┌─────────────────────────────────────────────────────────┐
│  1  填写小程序信息 / 类目 / 备案 / 认证（可并行开发）      │
├─────────────────────────────────────────────────────────┤
│  2  小程序开发与管理 → 下载开发者工具 → 上传代码           │
├─────────────────────────────────────────────────────────┤
│  3  版本管理 → 体验版测试 → 提交审核 → 发布上线            │
└─────────────────────────────────────────────────────────┘
```

### 首页四项任务说明

| 首页显示 | 当前状态示例 | 是否必须 | 说明 |
|----------|-------------|----------|------|
| **小程序信息** | 未填写 | ✅ 必须 | 名称、头像、简介 |
| **小程序类目** | 未补充 | ✅ 必须 | 不填无法提交审核 |
| **小程序备案** | 未备案 | ✅ 必须（新规） | **需先完成「信息 + 类目」** 才能备案 |
| **微信认证** | 未完成 | ⭕ 可选 | 认证后可被搜索/分享；**不认证也能发版** |

> **备案可与代码开发并行**：你可以一边写代码、一边填信息和备案，但**上架前必须完成备案**。

### 推荐操作顺序（首次发布）

```
1. 小程序信息  →  去填写
2. 小程序类目  →  去补充
3. 小程序备案  →  去备案（信息与类目完成后解锁）
4. 下载开发者工具，导入本项目，本地开发测试
5. 上传代码  →  体验版  →  提交审核  →  发布
6. （可选）微信认证  →  去认证
```

## 2. 第一步：填写小程序信息

### 2.1 小程序信息 → 去填写

路径：**设置 → 基本设置 → 小程序信息**，或首页点击 **「去填写」**。

| 字段 | 建议填写 |
|------|----------|
| 小程序名称 | `24点扑克` 或 `24点扑克闯关` |
| 小程序头像 | 扑克/数字 24 相关图标，清晰可辨 |
| 小程序简介 | `四张扑克牌，加減乘除拼出24，锻炼心算的益智小游戏。` |
| 服务范围 | 选「中国大陆」 |

### 2.2 小程序类目 → 去补充

路径：**设置 → 基本设置 → 服务类目**，或首页点击 **「去补充」**。

**推荐类目（按优先级）：**

| 优先级 | 类目路径 | 说明 |
|--------|----------|------|
| ⭐ 首选 | **工具 → 计算器** | 24 点本质是数学运算，审核相对简单 |
| 备选 | **教育 → 在线教育** | 若强调益智学习 |
| 慎用 | **游戏 → 休闲游戏** | 可能需要软著等游戏资质 |

> 类目选错是审核驳回的常见原因，优先选「工具-计算器」。

### 2.3 小程序备案 → 去备案

路径：首页 **「去备案」**，或 **设置 → 基本设置 → 小程序备案**。

**前置条件（首页会提示）：**

> ⚠️ **需先填写小程序信息和类目**，备案入口才会可用。

备案需准备（个人/企业要求不同，按页面提示）：

- 主体信息（个人身份证 / 企业营业执照）
- 小程序名称、简介（与上面一致）
- 负责人手机号、验证码
- 按指引完成管局审核（通常数个工作日）

**本项目备案说明可参考：**

```
小程序名称：24点扑克
功能描述：纯前端数学益智小游戏，用户用四张扑克牌通过四则运算得到24。
无用户登录、无支付、无网络数据传输，数据仅存本地。
```

### 2.4 微信认证 → 去认证（可选）

路径：首页 **「去认证」**，或 **管理 → 微信认证**。

| 项目 | 说明 |
|------|------|
| 认证作用 | 获得「被搜索」「被分享」等能力 |
| 是否阻塞发版 | **不阻塞**，首页明确写「未完成微信认证不影响后续版本发布」 |
| 建议 | 先上线 V1.0，有需要再认证 |

### 2.5 绑定开发者

路径：**管理 → 成员管理 → 项目成员**

- 确认你的微信号是 **管理员** 或 **开发者**
- 否则无法在开发者工具中上传代码

## 3. 第二步：开发并上传代码

对应首页 **「② 小程序开发与管理 → 自己开发 → 下载开发者工具」**。

### 3.1 本地自检

```bash
cd D:\code_2026\wechat-24-game
npm install
npm run check
```

### 3.2 导入项目

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 微信扫码登录（需为小程序开发者/管理员）
3. **「+」→ 导入项目**，填写：

| 字段 | 值 |
|------|-----|
| 项目目录 | `D:\code_2026\wechat-24-game` |
| AppID | `wx6b419d226271d30b` |
| 后端服务 | **不使用云服务** |

### 3.3 编译与真机预览

**模拟器检查：**

- [ ] 首页「开始闯关」「查看帮助」完整可见
- [ ] 游戏页四张牌、四则运算、四个操作按钮一屏可见
- [ ] 「提示」弹窗显示分步答案（不是操作说明）
- [ ] 答对后弹窗「恭喜你，算出了24」
- [ ] 帮助页正常

**真机预览：** 点击 **预览** → 微信扫码 → 完整走一遍。

### 3.4 预览报错处理

若出现 `ENOENT .../.git/cursor/crepe/...`：

1. **工具 → 清除缓存 → 全部清除**
2. 关闭项目，重新导入
3. 预览前等待 Cursor 索引完成，或暂时关闭 Cursor

> `project.config.json` 已配置忽略 `.git` 目录，重新导入后一般可解决。

### 3.5 上传代码

1. 开发者工具点击 **上传**
2. 填写：

| 字段 | 建议值 |
|------|--------|
| 版本号 | `1.0.0` |
| 项目备注 | `V1.0 24点扑克，首页/游戏/帮助，本地计分，随机出题` |

3. 上传成功后，代码出现在公众平台 **管理 → 版本管理 → 开发版**

### 3.6 本项目无需配置的内容

| 项目 | 是否需要 |
|------|----------|
| 服务器域名 | ❌ 不需要（无网络请求） |
| 云开发 | ❌ 不需要 |
| 用户隐私协议（复杂版） | ❌ 一般不收集用户信息 |
| 支付配置 | ❌ 不需要 |

## 4. 第三步：体验版测试

路径：**管理 → 版本管理**

1. 在 **开发版** 找到刚上传的版本
2. 点击 **选为体验版**
3. **管理 → 成员管理 → 体验成员** → 添加测试微信号
4. 体验成员扫描 **体验版二维码** 真机测试

**体验版检查：**

- [ ] 三项首页流程：首页 → 游戏 → 帮助
- [ ] 提示答案正确（分步解法）
- [ ] 撤销、重开、换题正常
- [ ] 无布局错位、无崩溃
- [ ] 与后续审核说明一致

---

## 5. 第四步：提交审核

路径：**版本管理 → 体验版 → 提交审核**

### 5.1 功能页面

| 页面 | 路径 | 功能说明 |
|------|------|----------|
| 首页 | `pages/index/index` | 游戏入口、开始闯关、查看帮助 |
| 游戏页 | `pages/game/game` | 24 点核心玩法 |
| 帮助页 | `pages/help/help` | 玩法与按钮说明 |

### 5.2 测试账号

无登录功能 → 填 **「无需测试账号」**（若平台允许留空）。

### 5.3 补充说明（可直接复制）

```
本小程序为 24 点扑克数学益智小游戏，纯前端实现。

功能说明：
- 随机生成 4 张扑克牌，题目自动保证有解
- 支持加、减、乘、除四则运算
- 支持撤销、重开、换题、分步提示答案
- 本地保存最高关卡、累计答对数、最快用时

无用户登录、无网络请求、无支付、无广告。
数据仅保存在用户手机本地。
```

### 5.4 隐私保护指引

路径：**设置 → 基本设置 → 用户隐私保护指引**

- 本项目不收集个人信息、不调用敏感接口
- 按页面引导选择「不收集用户信息」或等效选项

### 5.5 等待审核

- 通常 **1–7 个工作日**
- 在 **版本管理 → 审核版** 查看进度
- 驳回后按原因修改 → 重新上传 → 再提交

## 6. 第五步：正式发布

1. 审核通过后，**版本管理 → 审核版** 显示「审核通过」
2. 点击 **发布**
3. 确认后成为 **线上版**
4. 用户可通过搜索、小程序码进入

> 若提示需先完成备案，回到首页完成 **小程序备案** 后再发布。

## 8. 常见问题

### Q1：首页备案显示「需先填写小程序信息和类目」

按顺序完成：**小程序信息 → 小程序类目 → 备案**，三项都在首页有「去填写/去补充/去备案」按钮。

### Q2：上传时提示「无权限」

- 确认微信是小程序 **开发者/管理员**
- 确认 AppID 为 `wx6b419d226271d30b`

### Q3：提交审核提示「未设置服务类目」

**设置 → 基本设置 → 服务类目** 中添加，推荐「工具 → 计算器」。

### Q4：审核被驳回

- 检查体验版功能与说明是否一致
- 补充截图和测试步骤
- 确认类目与功能匹配

### Q5：预览 ENOENT `.git/cursor/...`

见 [3.4 预览报错处理](#34-预览报错处理)。

### Q6：不认证能发布吗？

**能。** 首页说明「未完成微信认证不影响后续版本发布」，认证主要影响搜索和分享能力。

### Q7：需要配置服务器域名吗？

**不需要。** 本项目纯前端，无 `wx.request` 等网络请求。
