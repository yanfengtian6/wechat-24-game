# 微信小程序 24 点扑克

一个从 0 开始搭建的原生微信小程序 24 点小游戏，纯前端实现，无服务端依赖。

## 功能

- 首页、游戏页、帮助页三页结构
- 扑克牌桌风格 UI
- 自动生成有解的 24 点题目
- 内置 24 点求解算法
- 支持撤销、重开、提示、下一题
- 本地存储最高分

## 运行方法

1. 安装并打开微信开发者工具。
2. 选择「导入项目」，项目目录选择本仓库根目录。
3. AppID 可使用测试号或微信开发者工具提供的游客模式。
4. 编译运行即可开始游戏。

## 本地检查

本项目没有 npm 依赖，检查脚本会验证关键文件、JS 语法和 24 点求解器：

```bash
npm run check
```
