# 微信小程序 24 点扑克

原生微信小程序实现的 24 点扑克牌闯关小游戏。项目为纯前端版本，不使用后端、不使用云开发、不接广告，微信开发者工具导入后即可编译运行。

## V1.0 功能

- 首页、游戏页、帮助页
- 深绿色牌桌背景与白底圆角扑克牌 UI
- 红桃/方块显示红色，黑桃/梅花显示黑色
- 随机生成 4 张扑克牌，题目自动保证有解
- 支持点击两张牌或表达式后使用 `+`、`-`、`×`、`÷` 组合
- 只剩一个表达式时自动判断是否等于 24
- 成功后弹窗提示“恭喜你，算出了24”
- 支持撤销、重开、换一题、提示答案
- 本地保存最高关卡、累计答对数、最快用时
- 预留“按住说答案（敬请期待）”按钮，V1.0 不接语音识别

## 用微信开发者工具导入

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择本仓库根目录：`D:\code_2026\wechat-24-game`。
4. AppID 使用已填写的项目 AppID。
5. 后端服务选择「不使用云服务」。
6. 点击「编译」，首页应显示“24 点扑克”，点击“开始闯关”进入游戏页。

## 本地自检

本项目不依赖复杂包，但建议先执行安装以生成/校验 npm 环境：

```bash
npm install
npm run check
```

`npm run check` 会检查：

- 关键小程序文件是否存在
- `app.json` 注册页面是否拥有对应的 `.js`、`.json`、`.wxml`、`.wxss`
- JSON 文件是否可解析
- JS 文件语法是否正确
- 24 点求解器是否能解出 `[3,3,8,8]`、`[1,5,5,5]`、`[6,6,6,6]` 等常见题目
- 随机生成的题目是否都有解

## 上传审核流程简述

1. 在微信开发者工具中点击「编译」，手动完成主要功能测试。
2. 点击「上传」，填写版本号，例如 `1.0.0`，备注填写 V1.0 功能说明。
3. 登录微信公众平台，在「版本管理」中找到体验版。
4. 设置体验成员并完成真机体验。
5. 确认无误后提交审核，按平台要求补充类目、隐私和功能说明。
